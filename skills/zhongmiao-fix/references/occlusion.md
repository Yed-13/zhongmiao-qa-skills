# 3D 装置遮挡（铁律 20）：怎么量、怎么修

铁律 20：互动装置不许被任何提示遮挡（题卡、精灵气泡、方法提示、反思框、开场卡、计算器……）；竖屏矮机必须实测；判据是**量出来的重叠**，不是「看着还行」。

## 先分清是哪种遮挡

| 类型 | 例子 | 量法 |
|---|---|---|
| DOM 浮层盖住 3D 装置 | 讲解卡、答题区压住装置 | 截图像素法（和仓库遮挡门禁同口径） |
| 3D 场景里的东西互相挡 | 角色立绘挡住坐标点、跳板 | 画布内读像素：隐藏/显示角色，比较装置像素 |
| DOM 标签互相挡 | 选项字母、悬牌被卡片压住 | 矩形交叠面积 ÷ 标签面积 |

仓库已有的工具先用：`scripts/qa/world_occlusion_gate.mjs`（DOM 浮层 vs 画布，基于预览路由）和 `scripts/qa/occlusion_pixels.mjs` 的 `analyzePixels`。看它们的文件头说明。

## 截图像素法（DOM 浮层 vs 装置）

在场景冻结后（`__tutorOcclusionProbe.freeze()` → `converge()` → `settle()`）拍四张、都裁到画布矩形：

- **B**：正常画面；
- **A**：隐藏画布以外的所有 DOM（只留画布和它的祖先）；
- **A0**：再隐藏装置（`setDeviceHidden(true)`）；
- **A2**：装置放回来（检查画面是否稳定）。

装置像素 = A 与 A0 不同、且 A 与 A2 相同的像素；被盖 = 这些像素里 B 和 A 不同的比例。用 `analyzePixels({A, A0, B, A2, ...})` 算，同时报「不稳定像素占比」。

注意：
- 画布容器里的 drei `<Html>` 标签是场景的一部分，隐藏 DOM 时要跳过它们（它们挂在 `canvas.parentElement.parentElement` 下面），否则小屏上标签压横梁会被算成「被盖」。
- `converge()` 不看相机投影矩阵；带取景缓动的世界要等你自己暴露的 `settled` 标志。
- 量具要先报一次红：在画布上盖一块不透明色块，确认读数接近 100%；不盖时接近 0。读不出来要当成「量具失效」，不是「没遮挡」。

## 画布内读像素（3D 物体 vs 装置）

- 通过 R3F 的根状态拿到场景（开发模式下从 Vite 依赖 URL 引 `@react-three/fiber` 的 `_roots`，`_roots.get(canvas).store.getState()`），用 WebGL `readPixels` 读三遍：全部可见 / 隐藏角色 / 逐个隐藏装置。
- 隐藏装置用 `material.colorWrite=false, depthWrite=false`，**不要**用 `layers.mask=0`——后者连影子一起去掉，地面上的影子会被误算成装置像素。
- 只数装置内部像素（去掉 1px 抗锯齿边），边缘本来就会和背后混色。

## 普查（逐题、逐尺寸）

- 一个单元开一个页面，用做题钩子按顺序走完每题，每个状态量一次；不要每题重新加载页面（慢得多）。
- 修前修后各用一个 worktree（同一基点），各自的依赖缓存，可以并行跑。
- 尺寸只挑撑得起结论的：几个宽屏 + 两个窄屏（如 1366×768、1280×720、390×844、375×667、320×568），不要为凑数跑一堆。
- 噪声：页面刚加载后的第一题、多页面并发时，常读出 3–7% 的「被盖」并伴随 10–20% 不稳定像素；单独重测多半是 0。不稳定像素高的格子要单独重测再报。
- 庆祝语等随机文案会改变布局：比较前先在初始化脚本里固定 `Math.random`。
- 结果表写「修前 → 修后」，最差的格子写进括号；非零残留逐条解释（噪声 / 真实残留 / 为什么不修）。

## 团队接受的修法

- **不要缩小或框住 3D 画布**。「场景变小但没被挡」在团队看来等于「3D 变成了背景」，被否决过；硬边框贴在画面上也不接受。
- 优先：画布保持全屏，用相机让位（例如 `camera.setViewOffset` 把取景移到空出来的区域），同时缩小/移动浮层（长选项改一行、提示条挪到侧栏）。
- 「稍微偏离中心但大」优于「居中但小」。
- 不为一个世界去改所有世界共用的布局，除非问题本身就是共用布局。
- **先给用户看对比图再做全量普查**：修前 / 方案 A / 方案 B 同一状态拼一张图，用户选了再量。

## PR 里要写的

- 量法一句话（哪种方法、哪些装置、阈值）。
- 修前 → 修后的表：尺寸 × 状态，最差格子。
- 截图：每个关键状态一张修前|修后拼图，含竖屏矮机。
- 未测：真机、其他同写法的世界、没覆盖的状态（例如过场动画）。
